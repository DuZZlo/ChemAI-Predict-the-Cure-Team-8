## Описание проекта

Разработан воспроизводимый вычислительный пайплайн для многоцелевого прогнозирования фармакологических свойств малых молекул против штаммов вируса гриппа.

На основе вектора физико-химических дескрипторов RDKit осуществляется одновременная оценка трёх целевых показателей:

- **IC50** - полумаксимальная ингибирующая концентрация (терапевтическая эффективность). Чем ниже, тем лучше.
- **CC50** - полумаксимальная цитотоксическая концентрация (токсичность на клеточной линии). Чем выше, тем безопаснее.
- **SI** (Selectivity Index) - индекс селективности = CC50 / IC50. Характеризует широту терапевтического окна безопасности.

## Архитектура вычислительного пайплайна

Пайплайн включает пять последовательных этапов.

**Этап 1. Предобработка и отбор признаков**

- Импутация пропусков медианой тренировочной выборки.
- Удаление признаков с дисперсией ниже 0.001 (константы и квазиконстанты).
- Ранговый отбор топ-12 признаков по корреляции Спирмена с целевыми переменными.

**Этап 2. Нелинейное расширение признаков**

- Логарифмическая трансформация (log1p) для стабилизации дисперсии.
- Генерация матрицы парных отношений - 66 попарных делений топ-12 признаков с защитой от деления на ноль.
- Гауссов фактор липофильности, моделирующий параболическую зависимость биодоступности от logP с оптимумом около 2.5 (правило Липинского).
- Сглаженное целевое кодирование химических фрагментов (fr_*) с весом сглаживания 4.

**Этап 3. Снижение размерности и топологический эмбеддинг**

- Сжатие матрицы отношений методом главных компонент (PCA) до 7 ортогональных факторов.
- Построение матрицы евклидовых расстояний между молекулами по 15 стерическим дескрипторам.
- Извлечение 3 координат структурного сходства через PCA (топологический эмбеддинг).

**Этап 4. Каскадная регрессия и обучение на остатках**

- Каскад (Chained Targets): модель IC50 обучается первой на 5-кратной кросс-валидации. Её OOF-предсказания (Out-of-Fold) передаются как дополнительный признак для моделей CC50 и SI.
- Ансамбль для IC50: CatBoost + LightGBM + KNN с весами 0.8 и 0.2.
- Двухэтапное обучение на остатках для CC50 и SI: сначала LightGBM даёт базовый прогноз (MSE), затем CatBoost обучается на остатках с функцией потерь MAE (L1-метрика). Это обеспечивает устойчивость к выбросам.
- Таргет-фьюжн для SI: финальное предсказание усредняется 50/50 между прямым предсказанием модели и аналитическим отношением CC50_pred к IC50_pred. Это компенсирует математическое смещение.

**Этап 5. Пост-процессинг**

- Soft-clipping через гиперболический тангенс (tanh).
- Клипирование по 99.8-му перцентилю тренировочных данных для предотвращения физически нереалистичных экстремальных значений.

## Используемые модели и гиперпараметры

**LightGBM (IC50):** n_estimators=2000, lr=0.0218, max_depth=4, num_leaves=8  
**LightGBM (CC50):** n_estimators=2700, lr=0.0188, max_depth=3, num_leaves=28  
**LightGBM (SI):** n_estimators=2900, lr=0.0244, max_depth=4, num_leaves=9  

**CatBoost (базовый):** iterations=2500, lr=0.025, depth=4, loss=RMSE  
**CatBoost (остатки):** iterations=2000, lr=0.020, depth=4, loss=MAE  

**KNN:** n_neighbors=3, weights=distance

Взвешивание ансамбля: LightGBM + CatBoost = 0.8, KNN = 0.2

## Инструкция по запуску

**Требования:** Python 3.8+, Google Colab (рекомендуется) или Jupyter Lab.

**Установка зависимостей:**
pip install catboost lightgbm scikit-learn scipy pandas numpy matplotlib

**Шаги для воспроизведения результата:**

1. Поместите файлы train.csv, test.csv и sample_submission.csv в директорию data/.
2. Запустите скрипт инициализации: `python initfile.py`
3. Откройте ноутбук `notebooks/Команда8_Вариант22.ipynb`
4. Выполните все ячейки последовательно (Run All).

После завершения работы в корневой директории появится файл с предсказаниями.

**Важно:** Пайплайн полностью автономен, не требует внешних API или баз данных. Воспроизводимость гарантирована фиксацией random_state=42 во всех случайных процессах. Каскад использует только OOF-предсказания — утечка данных отсутствует.

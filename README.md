# Прогнозирование биологической активности и цитотоксичности органических соединений против вирусов гриппа методами каскадного градиентного бустинга и топологического анализа

## Описание проекта

Настоящая работа посвящена разработке воспроизводимого вычислительного пайплайна для многоцелевого прогнозирования фармакологических свойств малых молекул против штаммов вируса гриппа (Influenza). На основе вектора физико-химических дескрипторов RDKit осуществляется одновременная оценка трех целевых показателей:

- IC50 - полумаксимальная концентрация ингибирования (терапевтическая эффективность);
- CC50 - полумаксимальная токсическая концентрация (цитотоксичность на клеточной линии);
- SI (Selectivity Index) — индекс селективности соединения (широта терапевтического окна безопасности).

Разработанная архитектура позволила минимизировать среднеквадратичную ошибку (RMSE) до уровня 267.218 на независимом тестовом множестве.

## Архитектура вычислительного пайплайна

### 1. Предварительная обработка и нелинейный отбор дескрипторов

**Импутация пропусков:** Лабораторные пропуски (NaN) в дескрипторах заполняются робастной медианой тренировочной выборки для предотвращения сингулярности математических расчетов.

**Ранговый анализ Спирмена:** Рассчитывается коэффициент монотонной корреляции Спирмена для каждого дескриптора относительно целевых переменных. Выделяется подмножество топ-12 признаков, обладающих максимальным монотонным сигналом.

**Фильтрация дисперсии:** Из вычислительного графа синхронно удаляются признаки с дисперсией ниже порога 0.001 (константы и квазиконстанты), что снижает размерность и устраняет информационный шум.

### 2. Нелинейное расширение признакового пространства

**Трансформация масштаба:** Для дескрипторов с непрерывным положительным диапазоном рассчитывается признак log_c через функцию np.log1p для стабилизации дисперсии.

**Матрица пропорций (r_i_j):** На основе топ-12 признаков по Спирмену генерируется полная комбинаторная матрица парных отношений со смещением 1e-8 в знаменателе для защиты от деления на ноль.

**Моделирование кинетики проницаемости:** В структуру данных интегрируется радиально-базисный гауссов фактор липофильности с оптимумом в области MolLogP порядка 2.5, аппроксимирующий параболическую зависимость биодоступности молекулы (правило Липинского).

**Сглаженное целевое кодирование:** Признаки химических фрагментов (fr_) переводятся в непрерывный масштаб ожидаемой активности (сглаживание с весом 4) раздельно под каждый профиль: через логарифм эффективности для IC50 и логарифм токсичности для CC50.

### 3. Снижение размерности и топологический эмбеддинг

Сгенерированная матрица отношений пропорций сжимается методом главных компонент (PCA) в 7 ортогональных факторов, ликвидируя мультиколлинеарность.

На основе попарных евклидовых расстояний (scipy.spatial.distance.cdist) между объектами выборок формируется матрица геометрического сходства структур по 15 ключевым стерическим факторам. После декомпозиции через PCA извлекаются 3 непрерывные пространственные координаты структурной близости молекул.

### 4. Каскадная регрессия и двухэтапное обучение на остатках ошибок (L1)

**Каскад (Chained Targets):** Обучение выстроено в сквозную цепь. Трехкомпонентный консенсус (CatBoost + LightGBM + KNN с весами 25%, 65%, 10%) на кросс-валидации 5-Fold K-Fold строит out-of-fold (OOF) предсказания для IC50. Данный вектор передается как новый сильный признак в пространство моделей CC50 и SI, выравнивая биологическую симметрию целевых показателей.

**Обучение на остатках (Residual Learning):** На этапах прогнозирования токсичности и индекса селективности применяется двухшаговое обучение. Базовая модель LightGBM формирует первоначальный вектор прогноза. Накопленный вектор остаточной ошибки (Residual = Target - LGB_Pred) передается в модель CatBoost.

**Медианное сглаживание остатков:** Модели остатков CatBoost оптимизируются по критерию минимизации средней абсолютной ошибки (MAE). Использование L1-регуляризации на этапе аппроксимации остатков сглаживает кусочно-постоянные ступени бустинга и предотвращает смещение на экстремальных выбросах распределения.

**Пост-процессинг:** На выходе аналитический индекс селективности усредняется в пропорции 50/50 с прямым логарифмическим прогнозом, компенсируя математическое смещение Jensen's Inequality, после чего применяется мягкий клиппинг хвостов через гиперболический тангенс (tanh) на уровне 99.8-го перцентиля.

## Структура репозитория

* **data/** - директория, содержащая исходные лабораторные выборки органических соединений (тренировочное и тестовое множества дескрипторов).
* **notebooks/** - каталог с исполняемыми файлами исследований, включающий промежуточные эксперименты по отбору признаков, полуобучению, топологическому анализу и итоговый воспроизводимый пайплайн.
* **submissions/** - директория экспорта файлов прогнозов, сгенерированных различными конфигурациями ансамблей моделей для верификации на проверяющей платформе.
* **README.md/** - отчетная документация проекта с описанием методологии Data Engineering и архитектуры каскадного моделирования.

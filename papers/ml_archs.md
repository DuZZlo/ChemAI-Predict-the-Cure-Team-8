## Выжимка исследования

**Цель:** Систематическая оценка 7 архитектур машинного обучения для предсказания биоактивности ингибиторов киназ.

**Данные и дизайн:**
- Датасет на основе ChEMBL: **352 874 записи**, **507 мишеней** (человеческие протеинкиназы)
- 3 стратегии разделения данных по возрастанию строгости: *случайное*, *по скаффолдам (Bemis–Murcko)*, *с исключением мишеней (target-held-out)*
- 5 случайных сидов для каждого эксперимента (всего 105 запусков)

**Протестированные модели:**
| Классические базлайны | Нейросетевые подходы |
|----------------------|---------------------|
| Random Forest, XGBoost, ElasticNet, MLP | GIN, ESM-2 embeddings + MLP, GNN-ESM fusion |

**Ключевые результаты:**
1. **Random Forest с отпечатками Morgan** показывает сопоставимую или лучшую производительность, чем все нейросетевые архитектуры, при строгой оценке (скаффолд- и target-held-out).
2. **Замороженные эмбеддинги ESM-2** хуже обобщаются на новых мишенях; наибольшая деградация — у модели ESM-FP MLP.
3. **Графовые представления (GIN)** не превосходят фиксированные 2048-битные отпечатки ECFP4 при данном объёме данных.
4. **Оценка неопределённости:** методы на основе деревьев калибруются лучше, чем протестированные реализации MC-Dropout.
5. **Кейс JAK-подсемейства:** 
   - Протеин-осознанные модели: **79%** точности top-1 селективности
   - Пулл-отпечатки: **52%**
   - Базлайны с явной идентичностью мишени: **83–84%** → эмбеддинги ESM-2 в данном исследовании работали преимущественно как *неявный идентификатор мишени*.

**Главный вывод:** Методология оценки и статистическая строгость оказывают решающее влияние на заявленную производительность моделей предсказания биоактивности. Простые, хорошо настроенные базлайны часто не уступают сложным архитектурам при реалистичных сценариях валидации.

# 📋 Выжимка: Antiviral Prediction using Machine Learning

## 🔬 Цель исследования
Разработка и сравнение моделей машинного обучения для предсказания противовирусной активности соединений против мишеней COVID-19.

## 📊 Данные
| Этап | Количество соединений | Примечание |
|------|----------------------|------------|
| Исходный набор CAS | ~290 000 | SAR-данные по противовирусным соединениям |
| С отчётом по IC₅₀ | 59 872 | Только количественные данные активности |
| После фильтрации по мишеням | 5 572 | Исключены 36 нерелевантных терапевтических направлений |

- **Дескрипторы:** 1 157 двумерных молекулярных дескрипторов

- **Алгоритмы:** Random Forest, XGBoost, SVM, KNN, Decision Tree, MLP Classifier, Logistic Regression
- **Валидация:** внутренняя + внешняя (независимый тестовый набор)
